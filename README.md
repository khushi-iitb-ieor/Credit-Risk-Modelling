# Credit Risk Modelling

## 📌 Overview
This project predicts whether a customer will default on credit using Logistic Regression.  
The goal is to help financial institutions assess risk before giving loans.

---

## 📊 Dataset Information
- Total Records: 466,285  
- Total Features: 75  

👉 Full dataset: https://drive.google.com/file/d/1VOy91bx2xIAL72xuS6F8ICsVQFDNbsUU/view?usp=drive_link

---

## ⚙️ Project Workflow
1. Data Cleaning
2. Handling Missing Values
3. Feature Engineering
4. Encoding Categorical Variables
5. Model Building (Logistic Regression)
6. Evaluation

---

## 📈 Model Performance
- Accuracy: 41%
- Precision (Default): 96%
- Recall (Default): 35%
- F1 Score: 0.49
- AUROC: 0.69
- KS Statistic: 0.29

## 💰 Business Impact (Expected Loss)

- Expected Loss Ratio: **10.6%**

This means that for every ₹100 disbursed, the bank is expected to lose ₹10.6 due to defaults.

This metric helps financial institutions:
- Estimate potential losses  
- Make better lending decisions  
- Adjust risk thresholds
